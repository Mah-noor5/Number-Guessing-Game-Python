# 🎯 Number Guessing Game (Python)

A console-based Number Guessing Game developed in Python.

## 📖 Description

This game generates a random secret number based on the selected difficulty level. The player has limited attempts to guess the correct number. Hints are available depending on the difficulty, and scores are calculated based on performance.

## ✨ Features

- Four difficulty levels:
  - Easy
  - Medium
  - Hard
  - Expert
- Input validation
- Hint system
- Score calculation
- Leaderboard system
- Session statistics
- User-friendly console interface

## 🛠️ Technologies Used

- Python 3
- Random module
- File handling
- Functions
- Loops
- Exception handling

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Open a terminal in the project folder.
3. Run:

```bash
python project.py
```

## 📷 Sample Gameplay

- Enter your name
- Select a difficulty
- Guess the secret number
- Earn points
- View your leaderboard ranking
